# Screenshots

The README references three screenshots that should be added before submitting:

| File | What to capture |
| --- | --- |
| `docs/screenshot-home.png` | Home page — hero, stats, “Most connected people” grid |
| `docs/screenshot-profile.png` | A user profile — “People you may know” ranked list with mutual-friend counts |
| `docs/screenshot-degrees.png` | Degrees of separation — a shortest-path chain between two people |

With the app running (`npm start`), visit the pages above and capture with your OS screenshot tool
(Win+Shift+S on Windows, Cmd+Shift+4 on macOS). Optionally, also record a short screen recording of
the flow: search → profile → suggestions → degrees of separation.
